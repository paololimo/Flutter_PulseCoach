## Extracted facts — v1 (ground truth)

**Visual identity (DESIGN.md material):**
- Philosophy: *Dark canvas, living accents* — color is never decorative (action / state / completion only). Calm energy, "Calm meets Oura", no gym aggression, no exclamation marks.
- Palette (dark, default) confirmed in live code `lib/core/theme/pulse_coach_theme.dart`: surface `#0F1119`, surfaceContainer `#171B26`, surfaceContainerHigh `#1E2333`, primary `#7DD3C0` (aqua), secondary `#A78BDA` (violet), tertiary `#E8C87A` (amber), onSurface `#E2E4EA`, onSurfaceVariant `#9498A6`, error `#F28B82`. Light mode now has concrete values in code (surface `#F8FFFE`…).
- Session-type accents: Mobility=primary aqua, Cardio=`#F0A1B0` soft coral, Breathing=secondary violet.
- State colors: Active=primary, Fatigued=secondary, AtRisk=tertiary, Recovering=secondary @70%.
- Type: Plus Jakarta Sans (display/body) + JetBrains Mono (timers/numerics). Full scale documented; tablet +20%.
- Spacing: 8dp base (xs4/sm8/md16/lg24/xl32/2xl48). Airy density. Shape radii: card 16, button 12, chip/input 8, circular for ring/RPE/dots. No sharp corners.
- Elevation: surface-tint not shadows (3 levels). Icons: Lucide (UI, 1.5px stroke) + Lottie (session types).
- Animation tokens: micro 200–400ms ease-out; state 300ms ease-in-out; spatial 400–600ms; readiness 700ms/beat linear; auto-dismiss 3000ms+300ms fade. Full Reduce-Motion handling.

**Experience (EXPERIENCE.md material):**
- One-line test: *"Open the app and it already tells you what to do — and it always guesses how you feel."* Mental model: **personal DJ who knows your body** (Spotify autoplay).
- 5 principles: Decide-for-user-explain-after · Warmth over metrics · Resolve-don't-linger · Calm energy · Invisible intelligence-visible care. Emotional core: **Capable / Understood / Competence-not-welcome**. *Silence is a feature.*
- IA (phone): bottom `NavigationBar` 3 tabs **Sessions | Today | Progress** (Today center = default). Drawer (live app) holds Profile/Settings/Privacy/Debug. Tablet: `NavigationRail` + master-detail. WearOS: separate passive companion target. Breakpoint: single @600dp.
- Core loop (zero-navigation): Open → Read → Start (3-2-1 countdown) → Do (full-screen overlay) → Close (RPE tap → 3s mini-summary → auto-return). In-session is overlay, not a route.
- Custom components: HeroSessionCard, CompactSessionCard, CompletedSessionCard, InSessionView, CountdownOverlay, CompletionRing(+pulse), RPEInput(10 buttons, two-row degrade <516dp), StateIndicator, ExplanationLine, MiniSummary.
- Feedback hierarchy: visual state change → animation → passive text ("Using saved data") → dialog (destructive only). No success toasts, no error modals, no streaks/badges, no spinners (shimmer only).
- 4 flows: Onboarding→first plan (<90s) · Daily loop · Return-after-absence (empathetic, no guilt) · Graceful degradation (silent). A11y floor: WCAG 2.1 AA, color-independence, 48dp targets, Reduce-Motion, text scale to 2.0×, full Semantics map. (Note: legacy spec deferred full screen-reader to post-MVP; v2 store launch likely promotes this.)

## Extracted facts — v2 (to design)

- v2 watershed: optional cloud backend. v1 stays **free, offline, account-free** tier; on-device personalization preserved (NFR28). Brand promise non-negotiable.
- New surfaces needed: (1) Navigation fix FR53 — back-affordance from secondary drawer screens; (2) Accounts/Auth (email+pwd, Apple, Google) FR54–57 + E2E-encrypted backup/restore + in-app account deletion FR77; (3) Pro subscription + Progress free/Pro history gate w/ grandfathering FR58–62; (4) Social: username/handle + visibility tiers (private default), friends, activity feed, comparison FR63–67; (5) Co-located live shared sessions: create/join via code+QR, momentary co-location check, group-adapted plan (min intensity / lowest level / union of constraints / shortest duration), real-time sync, per-participant RPE FR68–73; (6) Leaderboard & scoring (shared > solo points) FR74–76.
- **Counter-metrics (design must protect):** gamification must NOT increase AtRisk-state session starts nor push RPE above ≈6.5; free-tier retention must not drop after paywall. → central design tension: social/competition vs v1 calm/no-guilt ethos.

## v2 design decisions (Paolo, 2026-06-20)

1. **Social IA** = **4th bottom tab "Social"** → `Sessions | Today | Social | Progress` (Today stays default/center-of-gravity). Social tab holds: friends/requests, activity feed, leaderboard, shared-session CTA. Tablet adds a 4th NavigationRail destination.
2. **Pro paywall** = **contextual & silent**. No persistent banner, no proactive popups, no badges. Prompt appears only on tapping a locked feature: one calm line + `Scopri Pro` CTA + `non ora` dismiss, then resolves. Honors "resolve, don't linger" + "silence is a feature".
3. **Leaderboard** = **friends-only, ranking + points, no underlying detail** (NFR29). No global boards, no "you've been overtaken" notifications. Shared-session point bonus visible (incentivize training *together*, not *more*).
4. **Leaderboard podium medals** (Paolo, follow-up): add gold/silver/bronze medals for top-3. Must stay tasteful within the calm palette — a small medal glyph beside rank, NOT confetti/loud celebration. Reuse accent tokens (gold≈tertiary amber, silver≈onSurfaceVariant, bronze≈coral) rather than introducing saturated trophy colors.
5. **Navigation fix (FR53)** `[ASSUMPTION]` = AppBar `leading` back-affordance on every secondary (drawer-reached) screen returning to the primary shell. Confirm.

## Update 2026-07-06 — v1 Experience Polish (FR78 / FR81 / FR82)

Intent: **Update**. Trigger: Paolo — "milestone bar, streak card e icone fattori beneficerebbero di un pass in bmad-ux." Source of the three: new PRD requirements FR78/FR81/FR82 + `addendum.md` "Experience Polish mechanism notes" (added 2026-07-06). `addendum.md` added to DESIGN.md `sources:`.

**Conflict surfaced (hard, brand-law level):** two of the three collided head-on with finalized brand rules.
- FR81 "visible active-days streak" vs DESIGN.md frontmatter **"No streaks"** + Brand & Style "streak counters" named as the category enemy + Flow-3/anti-patterns "no streak reset / streaks weaponize guilt".
- FR78 "brief celebratory animation" vs DESIGN.md Do/Don't **"Confetti… celebration animation"** (Don't) + "Quiet completion: gentle pulse".
- FR82 factor icons = clean addition, no conflict.

**Resolutions (Paolo, 2026-07-06):**
1. **FR81 — calm reframe, no streak-mechanic.** Keep the signal (consecutive active days) but present as a calm continuity indicator: no flame, no don't-break-the-chain, no reset drama/notification; reads its current (incl. zero) value silently. DESIGN.md Brand & Style gained a "Streak-counter vs. active-days" distinction; frontmatter description softened "No streaks" → **"No streak-guilt"**. Single source of truth = the FR23 activity signal already in `BehavioralStateMachine` (no parallel counter).
2. **FR78 — dedicated but restrained micro-animation.** The "celebration" is one restrained finish-marker beat (checkered-flag settles + soft `{primary}` glow, ~300–400ms ease-out), distinct from the CompletionRing pulse, **never** confetti/particles/sound, and never extends beyond the finish marker. DESIGN.md Do/Don't widened to admit exactly this one sanctioned finish flourish. Reduce-Motion → static.
3. **FR82 — factor icons distilled directly.** Row of ~16dp Lucide glyphs (1.5px stroke, `on-surface-variant`) under the always-visible ExplanationLine on HeroSessionCard; each tappable to its one-line textual factor; shown only for factors that actually applied. Factors: exercise type, intensity, temperature, precipitation, AQI — **humidity deliberately excluded** (not captured by `WeatherContext`). Presentation-only over existing explainability FR13/FR14. AQI may tint `{tertiary}` amber as redundant emphasis, never sole carrier.

**Placement (Paolo, 2026-07-06):**
- Active-days → **dedicated `ActiveDaysCard` below the HeroSessionCard** on Today (not in the state bar, not inline in the hero). Designed within calm constraints so it reads as gentle state, not a trophy; intentionally below the fold so it never competes with the hero.
- Factor icons → **row of glyphs directly under ExplanationLine** on the HeroSessionCard (tappable for text detail).

**New components added to both spines:** `MilestoneProgressBar` (replaces the plain in-session `LinearProgressIndicator`), `FactorIconRow`, `ActiveDaysCard`. Frontmatter `components:` list, DESIGN.md Components + Do/Don'ts + Brand & Style + Today vertical rhythm, EXPERIENCE.md IA/Component Patterns/State Patterns/Voice&Tone/Interaction Primitives/Accessibility Floor/Anti-patterns/Flow 2 all updated. NFR38 (60fps + reduce-motion degrade) noted on the new animated elements. Both spines remain `status: final`, `updated: 2026-07-06`.

**Parked (not part of this pass):** the ongoing-session-notification feature (FR79/FR80/NFR39) and its `review-delta-notification.md` (PASS-WITH-FIXES, 5 HIGH gaps) — that is primarily a PRD/architecture concern; Paolo redirected this UX pass to the three polish components. **Reviewer Gate (2026-07-06)** — Paolo opted into two parallel lenses. Both returned PASS-WITH-FIXES → `review-brand-ethos-polish.md`, `review-accessibility-polish.md`.

Findings resolved into the spines + mock:
- **[HIGH brand] Active-days was still a chain.** "Consecutive days, reset to 0" is definitionally a streak; the 12→0 drop is the reset-shame event the ethos bans. **Resolution (Paolo): switch to a non-resetting rolling 30-day window** — "N giorni attivi negli ultimi 30". A rest day ages out silently; no snap-to-zero. Updated: DESIGN.md (ActiveDaysCard, Brand & Style distinction, Do/Don'ts), EXPERIENCE.md (Component Patterns, State Patterns return-after-absence, Voice&Tone example, Flow 2), mock copy. **⚠️ FR81 needs a matching PRD correct-course** — its current text ("consecutive calendar days… resets to zero") now diverges from the UX contract; flagged for `bmad-correct-course`.
- **[MED brand] Racing/victory metaphor + stacked completion beats.** Resolution: (1) finish marker is now a **neutral** dot/check, **not** a checkered flag; (2) the finish marker **settles quietly with no glow** — the single emotional close is the CompletionRing pulse in MiniSummary (Paolo's pick), and the two beats must never stack.
- **[BLOCKER a11y] FactorIconRow tap target.** ~16dp glyphs had no ≥48dp target. Resolution (Paolo kept the row tappable): each glyph gets a **≥48dp transparent hit-area**, non-overlapping, and the row **wraps** (never truncates) at 2.0×. Small-phone tightness accepted with the wrap fallback.
- **[HIGH a11y] Milestone contrast.** on-surface-variant tick on primary fill = 1.64:1; primary finish marker on primary fill = 1.00:1 (invisible, hue-only). Resolution: step boundaries are **notches in the fill** (+ rail tick); finish marker carries reached-vs-unreached by **shape** (outline→filled) with an `{on-primary}` fill ≥3:1. Updated in DESIGN.md MilestoneProgressBar + EXPERIENCE.md Accessibility Floor.
- **[HIGH a11y] FactorIconRow overflow at 2.0×** → added the "wrap, don't truncate, don't push Start off-hero" rule.
- **[MED/LOW]** thin 1.5px glyphs over the hero gradient wash (contrast caveat noted in DESIGN.md), aqua-vs-grey CVD, ActiveDaysCard caption ≥11sp + single semantics node — all captured.

Post-gate state: both spines remain `status: final`, `updated: 2026-07-06`. Mock `key-screens.html` (Today + In-Session) updated to show the corrected components.
