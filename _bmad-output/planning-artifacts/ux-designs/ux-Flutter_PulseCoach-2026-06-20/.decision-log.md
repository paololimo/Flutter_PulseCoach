## Extracted facts — v1 (ground truth)

**Visual identity (DESIGN.md material):**
- Philosophy: *Dark canvas, living accents* — color is never decorative (action / state / completion only). Calm energy, "Calm meets Oura", no gym aggression, no exclamation marks.
- Palette (dark, default) confirmed in live code `lib/core/theme/pulse_coach_theme.dart`: surface `#0F1119`, surfaceContainer `#171B26`, surfaceContainerHigh `#1E2333`, primary `#7DD3C0` (aqua), secondary `#A78BDA` (violet), tertiary `#E8C87A` (amber), onSurface `#E2E4EA`, onSurfaceVariant `#9498A6`, error `#F28B82`. Light mode now has concrete values in code (surface `#F8FFFE`…).
- Session-type accents: Mobility=primary aqua, Cardio=`#F0A1B0` soft coral, Breathing=secondary violet.
- State colors: Active=primary, Fatigued=secondary, AtRisk=tertiary, Recovering=secondary @70%.
- Type: Plus Jakarta Sans (display/body) + JetBrains Mono (timers/numerics). Full scale documented; tablet +20%.
- Spacing: 8dp base (xs4/sm8/md16/lg24/xl32/2xl48). Airy density. Shape radii: card 16, button 12, chip/input 8, circular for ring/RPE/dots. No sharp corners.
- Elevation: surface-tint not shadows (3 levels). Icons: Lucide (UI, 1.5px stroke) + Lottie (session types).
- Animation tokens: micro 200–400ms ease-out; state 300ms ease-in-out; spatial 400–600ms; readiness 700ms/beat linear; auto-dismiss 3000ms+300ms fade. Full Reduce-Motion handling.

**Experience (EXPERIENCE.md material):**
- One-line test: *"Open the app and it already tells you what to do — and it always guesses how you feel."* Mental model: **personal DJ who knows your body** (Spotify autoplay).
- 5 principles: Decide-for-user-explain-after · Warmth over metrics · Resolve-don't-linger · Calm energy · Invisible intelligence-visible care. Emotional core: **Capable / Understood / Competence-not-welcome**. *Silence is a feature.*
- IA (phone): bottom `NavigationBar` 3 tabs **Sessions | Today | Progress** (Today center = default). Drawer (live app) holds Profile/Settings/Privacy/Debug. Tablet: `NavigationRail` + master-detail. WearOS: separate passive companion target. Breakpoint: single @600dp.
- Core loop (zero-navigation): Open → Read → Start (3-2-1 countdown) → Do (full-screen overlay) → Close (RPE tap → 3s mini-summary → auto-return). In-session is overlay, not a route.
- Custom components: HeroSessionCard, CompactSessionCard, CompletedSessionCard, InSessionView, CountdownOverlay, CompletionRing(+pulse), RPEInput(10 buttons, two-row degrade <516dp), StateIndicator, ExplanationLine, MiniSummary.
- Feedback hierarchy: visual state change → animation → passive text ("Using saved data") → dialog (destructive only). No success toasts, no error modals, no streaks/badges, no spinners (shimmer only).
- 4 flows: Onboarding→first plan (<90s) · Daily loop · Return-after-absence (empathetic, no guilt) · Graceful degradation (silent). A11y floor: WCAG 2.1 AA, color-independence, 48dp targets, Reduce-Motion, text scale to 2.0×, full Semantics map. (Note: legacy spec deferred full screen-reader to post-MVP; v2 store launch likely promotes this.)

## Extracted facts — v2 (to design)

- v2 watershed: optional cloud backend. v1 stays **free, offline, account-free** tier; on-device personalization preserved (NFR28). Brand promise non-negotiable.
- New surfaces needed: (1) Navigation fix FR53 — back-affordance from secondary drawer screens; (2) Accounts/Auth (email+pwd, Apple, Google) FR54–57 + E2E-encrypted backup/restore + in-app account deletion FR77; (3) Pro subscription + Progress free/Pro history gate w/ grandfathering FR58–62; (4) Social: username/handle + visibility tiers (private default), friends, activity feed, comparison FR63–67; (5) Co-located live shared sessions: create/join via code+QR, momentary co-location check, group-adapted plan (min intensity / lowest level / union of constraints / shortest duration), real-time sync, per-participant RPE FR68–73; (6) Leaderboard & scoring (shared > solo points) FR74–76.
- **Counter-metrics (design must protect):** gamification must NOT increase AtRisk-state session starts nor push RPE above ≈6.5; free-tier retention must not drop after paywall. → central design tension: social/competition vs v1 calm/no-guilt ethos.

## v2 design decisions (Paolo, 2026-06-20)

1. **Social IA** = **4th bottom tab "Social"** → `Sessions | Today | Social | Progress` (Today stays default/center-of-gravity). Social tab holds: friends/requests, activity feed, leaderboard, shared-session CTA. Tablet adds a 4th NavigationRail destination.
2. **Pro paywall** = **contextual & silent**. No persistent banner, no proactive popups, no badges. Prompt appears only on tapping a locked feature: one calm line + `Scopri Pro` CTA + `non ora` dismiss, then resolves. Honors "resolve, don't linger" + "silence is a feature".
3. **Leaderboard** = **friends-only, ranking + points, no underlying detail** (NFR29). No global boards, no "you've been overtaken" notifications. Shared-session point bonus visible (incentivize training *together*, not *more*).
4. **Leaderboard podium medals** (Paolo, follow-up): add gold/silver/bronze medals for top-3. Must stay tasteful within the calm palette — a small medal glyph beside rank, NOT confetti/loud celebration. Reuse accent tokens (gold≈tertiary amber, silver≈onSurfaceVariant, bronze≈coral) rather than introducing saturated trophy colors.
5. **Navigation fix (FR53)** `[ASSUMPTION]` = AppBar `leading` back-affordance on every secondary (drawer-reached) screen returning to the primary shell. Confirm.
