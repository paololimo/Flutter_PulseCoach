### v2 scope brain dump (raw, from user)
1. **Navigation fix** — Settings/Profile drawer has no way back to Today/Sessions/Progress. Treat as a v2 UX requirement.
2. **Accounts + subscriptions** — to publish on App Store. **Architectural watershed:** v2 leaves the v1 "local-only / no server" posture and introduces backend, cloud accounts, and payments.
3. **Social (Strava-like)** — share progress, compare with friends, shared/group sessions, friends leaderboard where shared sessions award more points.
4. **Shared-session constraints** — (a) difficulty adapted to ALL participants (scale to common/weakest level); (b) participants co-located → geolocation required; (c) requires registered account + others in friend list.

### Remaining gaps resolved (2026-06-20, Fast path)
- **Auth providers:** Email+password, Sign in with Apple, Google Sign-In (all three).
- **Friend discovery:** unique username/handle, QR/invite link, phone contacts (all three).
- **Progress free/Pro boundary:** Free = last session + weekly goal only; Pro = full historical timeline + all `fl_chart` charts.

### Conflicts with v1 surfaced (must reconcile, not silently overwrite)
- **NFR11** "No user account, no email, no authentication required — profile data local-only" → v2 introduces optional accounts. Reconciled: account-free, offline, local-only experience preserved as the FREE tier; account optional, only required for backup + social/Pro.
- **NFR7** "All health/biometric data on-device — zero transmission for personalization" → v2 cloud sync + social sharing. Reconciled: adaptive AI stays on-device; cloud sync is opt-in, scoped to the user's own account (backup/restore + explicitly-shared social data), never centralized cross-user training. Biometrics still not required to leave device.
- **NFR17** "Data loss on uninstall accepted for v1" → resolved for signed-in users via cloud backup/restore.
- **NFR8 / FR35** "approximate city-level location only, no precise GPS" → shared-session co-location needs proximity. Reconciled via join-code/QR with GPS as soft, momentary, non-stored confirmation (not continuous tracking).

### Decisions (2026-06-20)
- **Working mode:** Fast path.
- **Monetization:** Freemium — core (Today/Sessions/Progress current + AI) stays FREE as in v1; **Pro subscription** gates the social suite (accounts-for-social, friends, shared sessions, leaderboard) **AND the extended Progress history/archive** ("storico"). Basic recent progress stays free; full history is Pro.
- **Shared sessions:** Live, synchronized (multiple users, co-located, shared state/timer — extends the existing phone↔WearOS live-session bridge to multi-user).
- **Co-location:** Join-code / QR at the same place; GPS is a soft confirmation, not a hard block.
