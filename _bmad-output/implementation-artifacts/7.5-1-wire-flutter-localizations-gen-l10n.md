## Correct-Course Note (2026-05-16)

AC2 and AC3 were amended during code review to reflect Flutter 3.41.6 tooling constraints discovered during implementation:

- **`arb-dir: lib/l10n` → `arb-dir: lib/l10n/app`** — the original AC2 value placed ARB inputs alongside the existing `lib/l10n/state_messages.it.arb`, which the dev reported as causing a `gen_l10n` conflict. Moving generator inputs to a dedicated subdirectory isolates them cleanly.
- **`synthetic-package: false` removed** — Flutter 3.41.6 rejects the `synthetic-package` key in `l10n.yaml`. Output location is preserved via `output-dir: lib/l10n` only.
- **Root-level stub files `lib/l10n/app_en.arb` + `lib/l10n/app_it.arb` deleted during code-review remediation** — they were dead source (not read by the relocated `arb-dir`) and a maintenance trap for translators.
- **Generated `app_localizations*.dart` files removed from version control and added to `.gitignore`** during code-review remediation — `generate: true` regenerates them on every `flutter pub get`, so committing them risks SDK-version-dependent dirty-tree CI failures. Project convention to commit generated files applies only to `build_runner` outputs (`.g.dart`, `.freezed.dart`).

Original AC text preserved in git history (commit predating this correct-course note).
