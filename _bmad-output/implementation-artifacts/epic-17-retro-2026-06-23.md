## Challenges & Discoveries

1. **Review "fixed" the paywall text leak but on-device proves it incomplete.** The 17.4 review switched `e.toString()` → `e.message` + Italian fallback, suite green — yet the device still shows the **English RevenueCat SDK string** ("There is no singleton instance… errors.rev.cat/configuring-sdk"), because for RC `PlatformException`s `e.message` *is* English SDK text and the Italian fallback only triggers when `message == null`. **Same class as Epic 16 (SignInSheet keyboard overflow) and Epic 9 (RPEInput 360dp):** the on-device gate sees what abstract review reasoning does not. Low severity (keyless state won't occur in production) → **E17R-1**.
2. **E16R-1 slipped through all 4 stories.** The Epic 16 action item said "schedule early in Epic 17, do NOT let it slip past 17.3." Each story's fire-check *noted* it (17.1 "after", 17.2 "after", 17.3 "in 17.4 or standalone", 17.4 "out of scope → Epic 18 kickoff"). Textbook "triggered-and-ignored" — the exact scenario E9R-4 was meant to prevent. The fire-check annotated it but never enforced it → **E17R-2 / E17R-3**.
3. **Doc-drift in epics.md AC2 (17.2).** epics.md listed "the most recent session and the weekly goal widget"; the delivered story + implementation show **only** the weekly goal widget + prompt. **Reconciled in `epics.md` in this retro session.**
