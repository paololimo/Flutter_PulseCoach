### AppShell Tab Order Change Details

**Current state** (`app_shell.dart`):
```dart
static const _tabs = [
  AppRouter.today,      // index 0 → Today
  AppRouter.sessions,   // index 1 → Sessions
  AppRouter.progress,   // index 2 → Progress
];

// BottomNavigationBar items (must match _tabs order):
BottomNavigationBarItem(icon: Icon(Icons.today), label: 'Today'),      // index 0
BottomNavigationBarItem(icon: Icon(Icons.fitness_center), label: 'Sessions'), // index 1
BottomNavigationBarItem(icon: Icon(Icons.bar_chart), label: 'Progress'), // index 2
```

**After this story**:
```dart
static const _tabs = [
  AppRouter.sessions,   // index 0 → Sessions
  AppRouter.today,      // index 1 → Today
  AppRouter.progress,   // index 2 → Progress
];

// BottomNavigationBar items (must match _tabs order):
BottomNavigationBarItem(icon: Icon(Icons.fitness_center), label: 'Sessions'), // index 0
BottomNavigationBarItem(icon: Icon(Icons.today), label: 'Today'),      // index 1
BottomNavigationBarItem(icon: Icon(Icons.bar_chart), label: 'Progress'), // index 2
```

`_currentIndex(String location)` is index-agnostic — it uses `_tabs.indexWhere(...)` so it updates automatically. No changes needed to that method.

`onTap: (index) => context.go(_tabs[index])` is also index-agnostic. No changes needed.

The `AppRouter.router` static definition in `app_router.dart` is **not affected** — the `ShellRoute` child routes are unordered, and the redirect logic (`_redirect`) uses path string constants (`today`, `sessions`, `progress`), not index positions. Do NOT touch `app_router.dart`.
