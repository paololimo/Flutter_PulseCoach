> **Version note:** The versions above are representative. Run `flutter pub outdated` to surface newer compatible versions. The constraint operator `^` allows compatible minor/patch upgrades. All versions must resolve without conflict under `sdk: ^3.11.3` (Dart 3.11.3+).

### Dependency Conflict Risk Areas

1. **`drift` ↔ `drift_dev`**: Must match major version exactly (both `^2.22.0`). Drift dev and runtime are released in sync — never mix major versions.

2. **`freezed` ↔ `freezed_annotation`**: `freezed` (code gen) must be compatible with `freezed_annotation` (runtime). Use versions from the same release cycle.

3. **`health` on iOS**: Requires HealthKit entitlements in `ios/Runner/Info.plist`. Not in scope for this story — flagged for Epic 3. Do NOT add entitlements here.

4. **`geolocator` on Android**: Requires location permissions in `AndroidManifest.xml`. Not in scope for this story — flagged for Epic 4.

5. **`wear_plus`**: Requires a separate WearOS module configuration. Not in scope until Story 12.1 spike. Including the dep here is safe; integration comes later.

### Architecture Compliance Guardrails

| Rule | Relevance |
|---|---|
| `dartz` provides `Either<Failure, T>` | Required for all repository returns (ARCH8) — ensure it's present |
| `shimmer` not `CircularProgressIndicator` | Loading states use Shimmer (ARCH10) — dep must be here |
| `freezed` + `json_serializable` code gen | All domain entities and bloc states (ARCH5) — both runtime annotation and dev gen packages needed |
| `drift` with `onUpgrade` migrations | NFR15-16: bandit state persists across updates — drift dep unlocks this in Story 1.4 |
| `flutter_animate` + `lottie` | UX-DR4 (Lottie session animations), UX-DR13 (animated onboarding), UX-DR18 (animation constants) |
| No `sqflite` or `sqlite3` direct dep | `drift_flutter` bundles the correct SQLite bindings — do NOT add `sqflite` or `sqlite3` separately |

### Critical Anti-Patterns to Avoid

| ❌ Do NOT | ✅ Do Instead |
|---|---|
| Pin to exact versions (`== x.y.z`) | Use `^` compatible version constraints |
| Add `sqflite` or `sqlite3` as direct deps | `drift_flutter` handles SQLite integration |
| Add `equatable` | `freezed` handles `==` and `hashCode` for all entities/states |
| Modify any `.dart` files | This story is pubspec-only |
| Add `path_provider` separately | `drift_flutter` bundles what's needed for the database path |
| Run `build_runner build` in this story | Code gen happens in Stories 1.3 and 1.4 |
| Gitignore `pubspec.lock` | Lock file MUST be committed — reproducible builds |
| Add `very_good_analysis` | Not in this project — use `flutter_lints` only (ARCH1, established in Story 1.1) |
| Add Firebase or any cloud SDK | Zero cloud backend per NFR7, NFR11 (privacy-first) |
