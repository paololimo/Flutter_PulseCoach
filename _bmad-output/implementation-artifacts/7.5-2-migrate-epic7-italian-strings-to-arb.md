# Story 7.5.2: Migrate Epic 7 Italian Strings to ARB

Status: done

## Story

As a developer,
I want every Italian string introduced during Epic 7 resolved through `AppLocalizations.of(context)` instead of being a hardcoded literal,
So that the Today screen is fully localized, the residual English "COMING UP" label is translated, and Epic 8 can extend the same pattern without first paying setup cost.

### ARB File Format for Parameterized Keys

Example of how to declare a parameterized key in `app_it.arb` and `app_en.arb`:

```json
{
  "@@locale": "it",
  "appTitle": "PulseCoach",

  "heroCardSemanticPreamble": "Prossima sessione: {displayName}, {durationLabel}",
  "@heroCardSemanticPreamble": {
    "placeholders": {
      "displayName": { "type": "String" },
      "durationLabel": { "type": "String" }
    }
  },

  "completionRingSemanticLabel": "Progressione giornaliera: {completed} di {total} sessioni completate",
  "@completionRingSemanticLabel": {
    "placeholders": {
      "completed": { "type": "String" },
      "total": { "type": "String" }
    }
  }
}
```

Generated Dart usage:
```dart
// Parameterized
l10n.heroCardSemanticPreamble(displayName, durationLabel)
l10n.completionRingSemanticLabel(widget.completed.toString(), widget.total.toString())

// Simple
l10n.stateLabelActive
l10n.comingUpHeader
```

### Anti-Patterns to Avoid

| ❌ | ✅ |
|---|---|
| Add `AppLocalizations l10n` to non-Flutter pure-Dart domain classes | Only widget files and their helpers get `l10n` — domain layer stays pure Dart |
| Retrieve `AppLocalizations.of(context)` in a static method without context | Pass `l10n` as a parameter to static helpers (`StateMessages.labelFor(state, l10n)`) |
| Use `l10n!` force-unwrap without assert | Use `AppLocalizations.of(context)!` — `assert()` in debug mode already guards; prod usage is safe because `app.dart` registers delegates globally |
| Rename existing test IDs (7.1-ARB-001, etc.) | Update test body and assertion, keep the ID stable |
| Skip updating the English ARB | Both `app_en.arb` and `app_it.arb` must have matching keys — gen_l10n fails if template ARB has keys missing from other locales |
| Hardcode `'it'` locale check in tests instead of using delegates | Always add the delegates; the Italian locale is enforced globally via `locale: const Locale('it')` in `app.dart` |
| Add localization delegates to tests that don't pump any Today-screen widget | Only update wrappers in files where the pumped widgets now call `AppLocalizations.of(context)!` |
