## What Went Well

1. **Clean hexagonal architecture.** `features/auth` split into domain/data/presentation with granular use cases and dedicated blocs — testable, layered, consistent with the rest of the codebase.
2. **ARCH25 boundary held and was enforced.** Only `lib/core/cloud/` imports `supabase_flutter`; the 16.2 violation (`auth_remote_data_source` importing the package directly) was caught at review and fixed via re-export. The review gate is load-bearing.
3. **Privacy by design is real.** 16.3 encrypts with Argon2id + AES-256-GCM; the key never leaves the device; only ciphertext + non-secret metadata are uploaded (NFR28).
4. **Free core is never blocked by auth (FR56/NFR34).** Verified on-device today — app runs fully with no session and empty cloud creds.
5. **Adversarial review on 16.4 was effective** — 0 patch findings, only 3 low-severity deferrals.

## Challenges & Recurring Patterns

1. **Layout defects only visible on real device with keyboard/narrow constraints.** The `SignInSheet` keyboard overflow was missed by widget tests (default 800dp-tall surface, no `viewInsets` simulation) and by dev self-check. **Same class as Epic 9** (RPEInput 360dp overflow). → E16R-2.
2. **Documentation discipline slipped at dev self-check (16.1).** Empty File List, wrong dev-notes (`anonKey` vs `publishableKey`), empty completion notes — exactly E15R-1/E15R-2. The rules worked *at review*, not at self-check. → E16R-4.
3. **Manual platform/cloud config debt.** Apple Developer Portal capability, Supabase dashboard Google redirect URLs, `google-services.json` secret handling, iOS `REVERSED_CLIENT_ID`. "Invisible until needed" — the reason real OAuth was N/A today. Recurs into Epic 17 (RevenueCat store products). → E16R-3.
4. **Epic-goal over-promise.** Epic 16's goal stated an "EntitlementGate skeleton"; no `entitlement_gate.dart` exists (it's scheduled in Story 17.1). `AuthBloc` is delivered; the gate is not. Not a blocker — 17.1 builds it first — but flagged for Epic 17 prep.
