## Challenges & Carry-Forward Risks

- **Release-build observability gap (10.0).** `AppLogger` is a no-op in release and nothing consumes `persistenceError` in the UI. In release, a failed `session_log` write produces no log, no UI signal, no telemetry — the user sees the session as completed while the DB has no row. Accepted as-designed for this milestone; **now promoted to a tracked follow-up (E10R-1)** per Paolo's decision.
- **UTC week-bucketing on non-UTC devices (10.3).** `_mondayOf` was unified to UTC (correct per the project "DateTime UTC internally" rule), but this shifts Story 10.2 weekly-minutes buckets for CET/CEST users — a session at Mon 00:30 local (Sun 22:30 UTC) buckets into the prior week. No dedicated non-UTC test exists. **Regression test scheduled (E10R-2)** — this is the actual target user's timezone.
- Minor deferrals recorded with rationale (no Category A slot): perpetual shimmer on `ProgressStatsError` (10.3 — folds into E10R-1); N+1 query in `getSessionHistory` (10.1); date rendering without `.toLocal()` near midnight (10.1, systemic); sticky `persistenceError` across stream ticks (10.0 — folds into E10R-1).
