### Exact Implementation for Task 2 — Failure Equality

**File:** `pulse_coach/lib/core/error/failures.dart`

Add `operator ==` and `hashCode` to the abstract base class only. All subclasses inherit the behavior:

```dart
abstract class Failure {
  String get message;
  const Failure();

  @override
  bool operator ==(Object other) =>
      identical(this, other) ||
      (other is Failure &&
          runtimeType == other.runtimeType &&
          message == other.message);

  @override
  int get hashCode => runtimeType.hashCode ^ message.hashCode;
}
```

**Why `runtimeType` in the base class:** Without it, `ServerFailure('x') == CacheFailure('x')` would be true because both extend `Failure` and have the same `message`. Using `runtimeType` ensures subclass identity is preserved in equality comparisons, matching the expected BLoC state deduplication semantics.

**Why no `Equatable` import:** `equatable` is available as a transitive dep through `flutter_bloc`, but the `Failure` base class lives in `lib/core/error/` (domain-adjacent core). Adding `equatable` as a direct dependency for four simple value classes would be over-engineering. The manual override is 4 lines, requires no `pub get`, and keeps the core layer dependency-free.

**Do NOT run `dart run build_runner build`** — no freezed, injectable, or drift-annotated classes are changed.
